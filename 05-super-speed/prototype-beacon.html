What this depends on
  • We don't know yet if these heroes also live far from where most help is needed. Distance counts for 60% of how the line is ordered, so moving someone up may not bring calls back by itself. We need location information from Wen.
  • The code already knows the difference between running out of time and saying no, but it counts them the same. We would count them differently.
  • We don't know why 60 seconds was picked, or what the records show for these heroes.
  • We haven't talked to a real hero. The screens are built from tickets and a practice round with simulated heroes.
